# Contributing Guidelines

## 🤝 Welcome
Thank you for your interest in contributing to **AI_Agent_Builder_Toolkit**!  
This project focuses on building **secure, real-time AI agents** aligned with the **5 Pillars of Secure AI Apps** and the **Anti‑Hallucination Framework**.

---

## 🧩 Core Principles
All contributions must follow these principles:

1. **Security First** – Apply the 5 Pillars:
   - Threat Modeling
   - Prompt Protection
   - Data Privacy
   - Model Integrity
   - Human Oversight

2. **Verification Discipline** – Follow the **Anti‑Hallucination Rules**:
   - Use only verified sources (PRD, API docs, logs, screenshots, test data, user input).
   - Label uncertain details as “Inference (low confidence)”.
   - Never invent features, APIs, or behaviors.
   - Ensure deterministic and repeatable outputs.

3. **Compliance Alignment** – Respect global standards:
   - GDPR, SOC 2, ISO 27001, DPDP Act.

4. **Transparency** – Every assertion must be traceable to source input.
